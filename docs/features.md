- [o] S12 — P1: Read and write text files, for the core checklist item F102.2. The sidecar reads request lines of up to 67108864 bytes instead of 16 MiB and writes replies without HTML escaping. `read` returns the text of a regular file with its SHA-256 `version`, its `newline` kind (`lf`, `crlf`, `cr`, `mixed`, `none`) and whether it starts with the UTF-8 BOM, and rejects a file that is not UTF-8, is above 8388608 bytes (checked before reading) or is not a regular file. `write` with an `expect` version opens the existing file without truncation, compares the SHA-256 read through the same descriptor, fails with `changed on disk` without writing when it differs, and otherwise writes from offset 0, truncates to the written length and synchronizes the file, so the inode, mode, extended attributes, hard links and symbolic links stay; with `expect` `null` it creates a new file with mode 0666 under the umask and fails with `exists`; a request without `expect`, `text` or `bom` is rejected. Paths are resolved like `list`; a path whose name leaves the root is rejected before it is looked up, and a new file resolves its parent directory. On macOS `watch` accepts a regular file and reports `{changed: path}` on kqueue `NOTE_WRITE` or `NOTE_EXTEND`; Linux watches directories only, so `TestWatchReportsAChangedFileContent` is skipped there. Red: with the previous implementation `TestServeReadsRequestLinesUpTo64MiB` failed with `serve: bufio.Scanner: token too long`; the eight `read` and `write` tests (`TestReadReportsTextVersionNewlineAndByteOrderMark`, `TestReadRejectsInvalidTextLargeFilesAndOtherFileTypes`, `TestReadAndWriteRejectPathsOutsideTheRoot`, `TestWriteWithExpectReplacesTheContentInPlace`, `TestWriteThroughASymbolicLinkKeepsTheLinkAndChangesItsTarget`, `TestWriteRefusesAChangeOnDiskWithoutWriting`, `TestWriteWithoutExpectCreatesOnlyANewFile`, `TestWriteRejectsInvalidRequestsAndLargeText`) failed with `unknown operation "read"` or `unknown operation "write"`; and `TestWatchReportsAChangedFileContent` failed with `open <file>: not a directory`. Green: the 17 Go tests pass, and `make test` passes on macOS 26.6.2 arm64.
